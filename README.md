# NexaClean Pro 3.4

**نکسا کلین پرو** یک ابزار دسکتاپ Windows برای پیدا کردن و پاک‌سازی فایل‌های تکراری، مدیریت هوشمند کتابخانه عکس و حذف پوشه‌های قدیمی/قفل‌شده است. رابط برنامه با Tkinter ساخته شده و پردازش‌های سنگین در Thread/Workerهای جدا انجام می‌شوند تا رابط کاربری تا حد ممکن پاسخ‌گو بماند.

> نسخه: **3.4**  
> سیستم هدف اصلی: **Windows 10 / Windows 11**  
> زبان رابط: فارسی  
> زبان برنامه: Python 3.10+

## نصب خیلی ساده

## دانلود از GitHub

در صفحه Repository روی **Code → Download ZIP** بزنید، ZIP را Extract کنید و `SETUP.bat` را اجرا کنید. Repository یک نسخه فشرده از سورس را هم نگه می‌دارد؛ GitHub Actions به‌صورت خودکار فایل خوانای `NexaClean_Pro.py` را Materialize می‌کند. اگر Action هنوز اجرا نشده باشد، `SETUP.bat` خودش همان فایل را قبل از نصب بازسازی می‌کند.

برای کاربر عادی نیازی نیست Python یا کتابخانه‌ها را دستی نصب کند.

1. فایل ZIP پروژه را Extract کنید.
2. روی `SETUP.bat` دوبار کلیک کنید.
3. Setup ابتدا Python 3.10+ را بررسی می‌کند. اگر Python وجود نداشته باشد و `winget` روی Windows موجود باشد، Python 3.12 را نصب می‌کند.
4. یک محیط مجازی محلی به نام `.venv` می‌سازد.
5. `Pillow`، `send2trash`، `psutil` و `opencv-python` را نصب می‌کند.
6. نصب را با Import کردن Tkinter و کتابخانه‌ها بررسی می‌کند.
7. Syntax فایل اصلی را بررسی می‌کند.
8. یک Shortcut با نام **NexaClean Pro** روی Desktop می‌سازد.
9. برنامه را اجرا می‌کند.

بعد از نصب، برای اجرای عادی فقط `RUN.bat` را بزنید. برای حذف اجباری پوشه‌های Access Denied بهتر است از `RUN_AS_ADMIN.bat` استفاده کنید. اگر برنامه بدون پنجره خطا بسته شد، `RUN_DEBUG.bat` را اجرا کنید تا خطا در Console دیده شود.

# قابلیت‌های اصلی

## 1. پیدا کردن فایل‌های تکراری به‌صورت Live

موتور Duplicate Scanner برای درایوها و پوشه‌های بزرگ به‌صورت مرحله‌ای کار می‌کند:

- پیمایش سریع پوشه‌ها با `os.scandir`.
- گروه‌بندی اولیه براساس **حجم فایل**؛ فایل‌هایی که حجم متفاوت دارند اصلاً Hash کامل نمی‌شوند.
- استفاده از **Quick Hash** با BLAKE2b از بخش ابتدایی، میانی و انتهایی فایل به‌عنوان فیلتر سریع.
- انجام **SHA-256 کامل** فقط برای مواردی که Quick Hash و حجم یکسان دارند.
- نمایش نتیجه تکراری در رابط کاربری به‌صورت Live؛ لازم نیست کل درایو تمام شود تا اولین نتیجه دیده شود.
- Queueهای محدود برای جلوگیری از ساخت میلیون‌ها Future و مصرف بی‌رویه RAM.
- توقف اسکن در هر لحظه.

### Worker خودکار

برنامه در Windows تا حد امکان نوع Storage را به‌صورت `SSD` یا `HDD` تشخیص می‌دهد و Workerها را براساس CPU، RAM آزاد و نوع دیسک تنظیم می‌کند. روی HDD عمداً Worker کمتر استفاده می‌شود، چون Thread زیاد می‌تواند Seek مکانیکی را شدید و اسکن را کندتر کند. روی SSD تعداد Workerها بالاتر انتخاب می‌شود.

## 2. حالت امن برای اسکن سیستم

گزینه **حالت امن: رد کردن Windows / Program Files** برای جلوگیری از ورود فایل‌های حساس سیستم به نتایج طراحی شده است. مسیرهایی مانند Windows، Program Files، ProgramData، System Volume Information، Recovery و فایل‌های ریشه‌ای حساس سیستم محافظت می‌شوند.

همچنین می‌توان فایل‌های خالی را در اسکن نادیده گرفت.

## 3. تشخیص فایل تکراری دقیق و عکس مشابه

دو نوع نتیجه وجود دارد:

- **دقیق (Exact):** محتوای باینری دو فایل بعد از SHA-256 برابر است.
- **تصویری (Visual):** برای تصاویر، یک Signature محافظه‌کارانه از dHash، نسبت تصویر و میانگین رنگ ساخته می‌شود تا برخی نسخه‌های یک تصویر با فرمت یا فشرده‌سازی متفاوت کنار هم پیدا شوند.

تشخیص تصویری اختیاری است و چون لازم است عکس‌ها Decode شوند، از اسکن Exact کندتر است.

## 4. پیش‌نمایش دوطرفه

برای هر Duplicate دو سمت نمایش داده می‌شود:

- **نسخه‌ای که نگه داشته می‌شود**
- **نسخه پیشنهادی برای حذف**

برای عکس‌ها Preview داخلی نمایش داده می‌شود. برای ویدئوها در صورت موجود بودن OpenCV یک فریم Preview ساخته می‌شود. برای فایل‌های دیگر نام، پسوند، حجم و مسیر نمایش داده می‌شود.

امکانات بررسی:

- باز کردن فایل.
- نمایش فایل در پوشه.
- جابه‌جایی Keeper و Candidate.
- رفتن به مورد بعدی.

## 5. حذف تکی و حذف گروهی Duplicateها

- حذف همین مورد.
- حذف همه Duplicateهای موجود در لیست.
- نمایش تعداد موارد قابل حذف روی دکمه حذف گروهی.
- گزینه **بعد از حذف خودکار برو مورد بعدی**.
- گزینه **حذف سریع بدون سؤال** زمانی که حذف به Recycle Bin امکان‌پذیر باشد.
- اگر `send2trash` نصب باشد حذف عادی به Recycle Bin می‌رود.
- فایل‌های محافظت‌شده سیستم برای حذف عادی مسدود می‌شوند.

# Force Folder Delete

تب **حذف اجباری پوشه** برای پوشه‌های قدیمی یا قفل‌شده‌ای است که Windows با `Access Denied` اجازه حذف معمولی آن‌ها را نمی‌دهد؛ برای مثال:

- `Windows.old`
- Windows قدیمی روی یک درایو دیگر
- پوشه‌ای از نصب قبلی Windows
- پوشه‌ای که Permission/Ownership آن خراب یا متعلق به حساب قبلی است

## 13. روند حذف اجباری

در نسخه 3.4 این بخش برای جلوگیری از گیرکردن روی پوشه‌های بسیار بزرگ Windows بازطراحی شده است:

1. مسیر انتخابی به فرمت Native ویندوز تبدیل می‌شود؛ برای مثال `D:/Windows` به `D:\Windows`.
2. ابتدا فقط مالکیت و Full Control **خود پوشه اصلی** با `takeown` و `icacls` اصلاح می‌شود؛ این مرحله سریع است.
3. برنامه قبل از اجرای عملیات سنگین، یک بار حذف مستقیم را امتحان می‌کند. اگر مجوزهای موجود کافی باشند، مراحل بازگشتی کاملاً رد می‌شوند.
4. فقط اگر فایل‌هایی باقی بمانند، `takeown` و `icacls` به‌صورت بازگشتی روی موارد باقی‌مانده اجرا می‌شوند. دسترسی به گروه داخلی Administrators با SID مستقل از زبان Windows داده می‌شود.
5. `attrib` برای برداشتن Read-only / System / Hidden اجرا می‌شود.
6. حذف نهایی انجام می‌شود و در صورت باقی‌ماندن فایل‌های قفل‌شده، امکان ثبت حذف برای Restart بعدی وجود دارد.

فرایندهای `takeown` و `icacls` دیگر با Pipe خروجی مسدود نمی‌شوند. برنامه هنگام عملیات طولانی هر چند ثانیه پیام «هنوز در حال اجراست» همراه با زمان سپری‌شده نشان می‌دهد، امکان توقف دارد و برای هر مرحله Timeout ایمنی در نظر گرفته شده است. بنابراین اجرای `icacls /T` روی ده‌ها هزار فایل دیگر نباید شبیه هنگ‌کردن برنامه باشد.

## محافظت‌های غیرقابل دور زدن در Force Delete

برای جلوگیری از حذف فاجعه‌بار، برنامه اجازه حذف اجباری موارد زیر را نمی‌دهد:

- ریشه کامل یک درایو مانند `C:\`
- Windows فعال سیستم
- Program Files فعال
- Program Files (x86) فعال
- ProgramData فعال
- کل پروفایل کاربر فعلی
- پوشه‌ای که شامل یکی از موارد فعال بالا باشد

Windows.old و Windows متعلق به نصب قدیمی روی یک درایو دیگر، در صورتی که Windows فعال نباشند، قابل بررسی برای حذف هستند.

> **هشدار بسیار مهم:** Force Folder Delete حذف دائمی است و از Recycle Bin استفاده نمی‌کند.

# روش استفاده پیشنهادی

## پاک کردن Duplicateهای یک هارد

1. وارد تب «فایل‌های تکراری» شوید.
2. پوشه یا درایو موردنظر را انتخاب کنید.
3. برای اسکن هارد کامل، حالت امن را روشن نگه دارید.
4. اگر فقط Duplicate دقیق می‌خواهید، تشخیص عکس مشابه را خاموش بگذارید تا سریع‌تر باشد.
5. «شروع اسکن» را بزنید.
6. نتیجه‌ها از همان حین اسکن وارد لیست می‌شوند.
7. چند نمونه را با Preview بررسی کنید.
8. در صورت اطمینان از دکمه حذف گروهی استفاده کنید.

## پاک‌سازی Screenshot و عکس‌های بی‌ارزش

1. وارد تب «مدیریت و پاکسازی عکس‌ها» شوید.
2. پوشه عکس‌ها را انتخاب کنید.
3. «اسکن عکس‌ها» را بزنید.
4. از دسته‌بندی سمت چپ «Screenshot / Capture»، «آیکون و فایل UI» یا «رزولوشن پایین» را انتخاب کنید.
5. با فیلترهای رزولوشن/حجم/جهت، لیست را محدودتر کنید.
6. عکس‌هایی را که مهم هستند «نگه دار» بزنید.
7. حذف فیلترشده‌ها به‌جز تیک‌خورده‌ها را اجرا کنید.

## حذف Windows.old

1. بهتر است برنامه را با `RUN_AS_ADMIN.bat` اجرا کنید.
2. وارد تب «حذف اجباری پوشه» شوید.
3. فقط پوشه موردنظر مثل `D:\Windows.old` را انتخاب کنید.
4. «بررسی مسیر» را بزنید.
5. گزینه‌های takeown، برداشتن Attribute و حذف بعد از Restart را در صورت نیاز روشن بگذارید.
6. تیک تأیید حذف دائمی را بزنید.
7. «حذف اجباری این پوشه» را اجرا کنید.
8. اگر برنامه اعلام کرد فایل‌هایی برای Restart زمان‌بندی شده‌اند، Windows را Restart کنید.

# مشکلات رایج

### SETUP.bat می‌گوید winget وجود ندارد
Python 3.10 یا جدیدتر را از python.org نصب کنید و دوباره `SETUP.bat` را اجرا کنید.

### برنامه با RUN.bat باز نمی‌شود
`RUN_DEBUG.bat` را اجرا کنید تا خطای Python در پنجره Console باقی بماند.

### حذف معمولی Access Denied می‌دهد
اگر فایل واقعاً فایل شخصی است، ممکن است توسط نرم‌افزار دیگری باز باشد یا Permission آن مشکل داشته باشد. برنامه/Explorer مربوط را ببندید و دوباره امتحان کنید. برای یک پوشه قدیمی قفل‌شده از تب Force Folder Delete استفاده کنید.

### Force Delete روی `takeown` خطای `File or Directory not found` می‌دهد
در نسخه 3.4 مسیر قبل از ارسال به ابزارهای Windows نرمال‌سازی می‌شود؛ بنابراین مسیرهایی که از رابط به شکل `D:/Windows` می‌آیند برای `takeown` و `icacls` به شکل `D:\Windows` فرستاده می‌شوند. اگر باز هم یک زیرمسیر خاص خطا بدهد، برنامه کل عملیات را متوقف نمی‌کند و روش بعدی را ادامه می‌دهد.

### `icacls` مدت زیادی طول می‌کشد
روی یک Windows قدیمی ممکن است ده‌ها یا صدها هزار ورودی وجود داشته باشد. نسخه 3.4 ابتدا حذف مستقیم را امتحان می‌کند و فقط در صورت نیاز `icacls /T` را اجرا می‌کند. در طول کار هر چند ثانیه Heartbeat در گزارش می‌بینید؛ دکمه توقف نیز فرایند و فرزندان آن را متوقف می‌کند.

### اسکن HDD با Worker زیاد کند است
این رفتار طبیعی Storage مکانیکی است. NexaClean تعداد Worker را برای HDD پایین‌تر نگه می‌دارد تا Seek تصادفی باعث افت سرعت نشود.

### آنالیز کیفیت عکس‌ها کند است
این گزینه نیازمند باز کردن و Decode تصویر است. برای اسکن اولیه خاموش نگه دارید و فقط برای پوشه عکس‌های شخصی روشن کنید.

# ساخت فایل EXE

دو روش برای ساخت نسخه مستقل Windows وجود دارد:

- روی سیستم خودتان `BUILD_EXE.bat` را اجرا کنید. فایل نهایی در `dist\NexaClean-Pro.exe` ساخته می‌شود.
- بعد از قرار گرفتن پروژه روی GitHub، Workflow موجود در `.github/workflows/build-windows.yml` در GitHub Actions می‌تواند نسخه Windows را خودکار Build کند و به‌صورت Artifact تحویل دهد.

این Build با PyInstaller انجام می‌شود و برای کاربر نهایی نیاز به نصب Python را از بین می‌برد. با این حال بسته ZIP دارای `SETUP.bat` نیز حفظ شده تا اجرای مستقیم سورس ساده باشد.

# نکته برای توسعه‌دهندگان

برنامه از Queue و ThreadPoolExecutor برای جدا نگه داشتن I/O و پردازش تصویر از Thread اصلی Tkinter استفاده می‌کند. Duplicate Scanner از Pipeline چندمرحله‌ای Size → Quick Hash → Full SHA-256 استفاده می‌کند و Smart Gallery برای جلوگیری از Freeze، تصاویر را صفحه‌بندی و Thumbnailها را Cache می‌کند.
