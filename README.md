# NexaClean Pro 3.5

ابزار ویندوز برای پیدا کردن فایل‌های تکراری، مدیریت و پاکسازی عکس‌ها و حذف پوشه‌های قدیمی/قفل‌شده.

## برای کاربر عادی

**فقط همین فایل ZIP را دانلود کن:**

### [⬇️ دانلود NexaClean-Pro-Windows-v3.5-OneClick.zip](./NexaClean-Pro-Windows-v3.5-OneClick.zip)

بعد از دانلود فقط این کارها را انجام بده:

1. ZIP را Extract کن.
2. روی **`NexaClean-Pro-START.bat`** دوبار کلیک کن.
3. بار اول، برنامه خودش Python و پیش‌نیازها را بررسی و نصب می‌کند.
4. دفعات بعد همان فایل START برنامه را مستقیم اجرا می‌کند.
5. Shortcut برنامه هم روی Desktop ساخته می‌شود.

کاربر عادی لازم نیست با فایل Python، RUN، SETUP، requirements یا فایل‌های فنی کاری داشته باشد.

## پوشه‌های فنی

این‌ها فقط برای توسعه هستند:

- `source/` — سورس برنامه و فایل‌های ساخت پکیج
- `docs/` — Changelog و نکات امنیتی
- `.github/workflows/` — ساخت خودکار EXE و ZIP

## قابلیت‌ها

- اسکن Live فایل‌های تکراری
- Quick Hash + SHA-256
- حذف تکی و گروهی Duplicateها
- Smart Photo Gallery
- دسته‌بندی Screenshot، Icon/UI، Cache و تصاویر کم‌کیفیت
- فیلتر بر اساس رزولوشن، حجم و جهت
- تیک «نگه دار» برای جلوگیری از حذف عکس‌های انتخابی
- Force Folder Delete برای Windows.old و Windows قدیمی
- گزارش زنده پیشرفت حذف، حجم آزادشده، زمان و نوع خطا
- تشخیص Access Denied، Locked file، Path Too Long و Reparse/Junction
- ذخیره گزارش عملیات در `%LOCALAPPDATA%\NexaClean Pro\logs`
